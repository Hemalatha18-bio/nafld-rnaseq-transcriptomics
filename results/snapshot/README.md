# Public GSE135251 results snapshot

This directory contains lightweight outputs generated by the versioned workflow from the public GEO GSE135251 processed RNA-seq counts.

The full raw download, gene-by-sample count matrix, normalized count matrix, and large intermediate tables are intentionally not committed. They can be regenerated with Snakemake from the public accession.

The default inferential contrast is NAFLD fibrosis F3-F4 versus F0-F1. Exploratory PCA uses filtered log2-CPM values; differential expression uses raw integer counts with DESeq2 and Benjamini-Hochberg FDR correction.
